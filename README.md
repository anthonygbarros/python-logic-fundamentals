# 🐍 Python Logic & Algorithm Fundamentals

This repository contains a curated collection of scripts and algorithms focused on solving practical engineering problems, fundamental data structures, and advanced core programming logic using **Python 3**.

---

## 🎯 Project Objectives

- Demonstrate proficiency in control flow, loops, and clean syntax in Python.
- Apply error handling (`try/except`), modular functions, and key data structures (Lists, Dictionaries, Sets, List Comprehensions).
- Establish a foundational showcase of code quality and software design principles (PEP 8).

---

## 🛠️ Technologies & Concepts Applied

- **Language:** Python 3.x
- **Control Structures:** `if`, `elif`, `else`, `while`, and `for` loops.
- **Data Structures:** Lists, Dictionaries, Sets, and List Comprehensions.
- **Error Handling:** Robust `try/except` blocks for runtime exception prevention.
- **Modular Code:** Reusable functions with clear scopes and docstrings.

---

## 🚀 How to Run

1. **Clone the repository:**
   `git clone https://github.com/anthonygbarros/python-logic-fundamentals.git`

2. **Navigate to the project directory:**
   `cd python-logic-fundamentals`

3. **Execute the main file:**
   `python main.py`
